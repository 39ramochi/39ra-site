39ra / SITE POLICY

PRIVACY
POLICY.

お問い合わせを通じて受け取る情報と、外部サービスの取り扱いについて。

01 / SCOPE

このポリシーについて

本ポリシーは、39ra公式サイト（以下「本サイト」）のお問い合わせフォームおよび本サイトで利用する外部サービスに関する情報の取り扱いを説明するものです。

02 / INFORMATION

取得する情報

お問い合わせフォームでは、お名前または活動名、返信先メールアドレス、お問い合わせ種別、本文を受け取ります。フォームの送信内容は、スパム対策のためのハニーポット項目を含む場合があります。

03 / PURPOSE

利用目的

受け取った情報は、お問い合わせへの返信、制作・楽曲利用に関する必要な連絡、および対応記録の管理のために使用します。独自のアクセス解析は、初回公開時には導入しません。

04 / CONTACT DELIVERY

FormspreeとGmail

お問い合わせフォームはFormspreeを経由して送信され、運営者が指定したGmailで受信します。FormspreeとGoogle/Gmailはそれぞれのサービスとして情報を処理・保管します。各サービスにおける保管期間、削除可否、利用条件は、それぞれのポリシーおよびアカウント設定に従います。

お問い合わせの記録は、対応完了から原則1年間保管し、期間経過後は、継続対応や法令上の保存が必要な場合を除き、運営者が削除操作できる範囲で削除します。外部サービス側の保存期間や完全削除の時期は、各サービスの規定に従います。

05 / EXTERNAL SERVICES

外部サービス

本サイトは、静的サイトの配信にGitHub Pages、お問い合わせの送信にFormspree、返信・連絡にGmail、楽曲の公式プレイヤー表示にSunoを利用します。Xへの外部リンクを利用した場合は、X側のポリシーが適用されます。各サービスの利用により、各事業者が技術情報等を取得する場合があります。

当サイトでは、一部の文字表示にGoogle Fonts（DM Sans、IBM Plex Mono）を利用しています。フォントの読み込みに際して、利用者のブラウザからGoogleのサーバーへ通信が発生し、IPアドレス等の情報が送信される場合があります。Googleにおける情報の取り扱いについては、Googleのプライバシーポリシーをご確認ください。

本サイトはメールアドレスをページ上に直接掲載しません。

06 / SECURITY

安全管理

お問い合わせ情報は、対応に必要な範囲で取り扱います。本サイトでは自前の問い合わせ管理データベースを設けず、フォームの受信・返信に必要な外部サービスを利用します。

07 / REQUESTS

お問い合わせ

ご自身の送信内容に関する確認、訂正、削除のご相談は、本サイトのCONTACTフォームからお送りください。内容を確認のうえ、対応可能な範囲でご案内します。

08 / CHANGES

改定について

本ポリシーは、サービス構成や運用の変更に応じて改定することがあります。
